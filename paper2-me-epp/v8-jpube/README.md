# v8-jpube

Working version for the redesigned JPubE paper:

**The Price of Exclusion: SME Set-Asides in Public Procurement**

This version is developed section by section from the optimized blueprint in
`docs/estrutura_paper_otimizada.md`. The v6 paper remains the source repository
for existing evidence, tables, macros, and appendices; v8 should only import
material that serves the central DAG:

```text
Legal shock
  -> SME-only rule
  -> non-SME exclusion + SME entry/composition
  -> effective auction pool
  -> price formation and allocation
  -> welfare
  -> set-aside vs price preference
```

Main-text target:

- 4 main tables.
- 3 main figures.
- 30-33 pages before references if possible.
- Robustness summarized around core threats, not displayed as a table farm.
