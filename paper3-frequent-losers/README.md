## Shared Dependencies

- **`BEC_collapse_final.dta`** — The main collapsed dataset (908 MB) is used by multiple papers in the monorepo. The canonical copy lives in `../data/processed/`.
- **`code/data-preparation/`** — Contains 31 shared Stata pipeline scripts for data preparation (not copied here).
- **v13/v14 scripts** — General thesis database organization scripts, also relevant to Paper 1 and Paper 2.

## Reproduction

1. Ensure Stata is available and raw BEC data is in `../data/`
2. Run the Stata scripts (v10–v12) in sequence for Paper 3 analysis
3. For Parquet conversion: `python scripts/convert_dta_to_parquet.py`
