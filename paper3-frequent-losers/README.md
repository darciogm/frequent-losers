## R Analysis Pipeline

Full R/fixest pipeline following Paper 2 conventions. Run from project root:

```bash
Rscript scripts/00_master.R      # Full pipeline (~80 seconds)
```

### Pipeline

| Script | Purpose | Key outputs |
|--------|---------|-------------|
| `utils.R` | Paths, helpers, `run_losers_4()`, `theme_pub()` | — |
| `01_clean.R` | Load 4 parquets, reverse-engineer BEC keys, merge LOSERS | `/tmp/p3_prepared.rds` |
| `02_analysis.R` | 12 regressions (3 DVs × 4 specs) | `/tmp/p3_models.rds` |
| `03_tables.R` | 4 LaTeX tables (desc stats + 3 regression) | `output/tables/tab_*.tex` |
| `04_figures.R` | 3 PDFs + 6 stubs (require bid-level data) | `output/figures/fig_*.pdf` |

### Key Technical Details

| Aspect | Detail |
|--------|--------|
| **Main regression** | `y ~ losers + convite \| item_f + year_f [+ pbu_f]` |
| **Clustering** | `~item_f` |
| **Treatment** | `losers` = 1 if tender has ≥1 frequent loser participant |
| **Sample** | Items with ≥1 loser tender, phases 2+3 (convite/pregão), winners only |
| **Sample size** | N = 1,673,837 (manuscript target: 1,671,773) |
| **DVs** | log(negotiated price), log(n_firms), log(n_bids) |
| **4 specs** | (1) General, (2) General+PBU FE, (3) Pregão only, (4) Convite only |
| **BEC key structure** | PBU(11) + year(4) + "OC"(2) + seq(5) + item_code + phase_digit + description |
| **R-squared** | Overall R-squared (to approximate Stata areg output) |

### Requirements

- **R 4.5+** with packages: `data.table`, `fixest`, `ggplot2`, `arrow`, `scales`
- Parquet files in `data/processed/` (see Datasets below)

### Known Limitations

- **Missing `lquantity`**: BEC_collapse_final lacks quantity data; item FE absorbs most variation
- **Phase code mapping**: `po_phase_code` approximates but does not perfectly match Stata's convite/pregão definition
- **Figures 3–8 stubbed**: Require bid-level data (firm × item × time) not available in collapsed parquets


2. Run the Stata scripts (v10–v12) in sequence for Paper 3 analysis
