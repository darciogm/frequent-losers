# Short cover note (Editorial Express text field, ~120 words)

Dear Editor,

We submit "Cheap Signals, Costly Proof: The Reach and Limits of Award-Layer
Screening in Cartel Enforcement," by Darcio Genicolo-Martins and Paulo Furquim
de Azevedo (INSPER), exclusively to JLEO; it is not under review elsewhere. The
paper asks how far cheap, legally thin award-layer records can order costly
proof-producing investigative effort before bid records are recovered. Using
São Paulo's BEC platform (2009–2019) and CADE adjudications, we validate a
minimal loser-side construct, disciplining it for opportunity, case
concentration, and timing, and develop a sequential award→bid cost-recall
frontier. The construct ranks forensic priority; it does not prove liability or
estimate damages. BEC microdata are confidential (proprietary-data exemption to
be requested); code and derived frames support replication. — Darcio
Genicolo-Martins (darcio.g.martins@gmail.com)
