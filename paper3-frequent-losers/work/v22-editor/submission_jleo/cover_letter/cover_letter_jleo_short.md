# Short cover note (Editorial Express text field, ~120 words)

Dear Editor,

We submit "Cheap Signals, Costly Proof: The Reach and Limits of Award-Layer
Screening in Cartel Enforcement," by Darcio Genicolo-Martins and Paulo Furquim
de Azevedo (INSPER), exclusively to JLEO; it is not under review elsewhere. The
paper's contribution is not a claim that an award-layer screen identifies cartel
members but a framework for auditing how far cheap administrative records can
order forensic priority before agencies open costly bid-level records. Using São
Paulo's BEC platform (2009–2019) and CADE adjudications, we build a reproducible,
non-circular adjudication-anchored label and decompose the ranking for
opportunity, case concentration, and timing; the audit is deliberately
deflationary — within comparable opportunity sets the residual ordering is
marginal at best and not robust across designs. We then develop a sequential
award→bid cost-recall frontier as a recovery-footprint accounting. The framework
ranks forensic priority; it does not prove liability or estimate damages. This is
enforcement design and evidence allocation under costly observability — a
law–economics–organization question. BEC microdata are confidential
(proprietary-data exemption to be requested); code and derived frames support
replication. — Darcio Genicolo-Martins (darcio.g.martins@gmail.com)
