# Reproducibility Linking Memo — v16

**Goal.** Make the v16 paper reproducible and cleanly linked to scripts/outputs while preserving v15 compatibility. Headline numerical claims are macro-bound to `values.tex`; included tables and figures are generated by versioned R scripts; the v15 build remains independently reproducible.

**Verified 2026-05-02.** v15 compiles 47pp + 22pp; v16 compiles 54pp + 22pp; both clean (zero errors above standard natbib boilerplate).

## I. How v16 compiles

### A. Build command (single round-trip)

From `work/v16-editor/`:

```bash
pdflatex -interaction=nonstopmode paper_v16editor_online_appendix.tex
bibtex   paper_v16editor_online_appendix
pdflatex paper_v16editor_online_appendix.tex
pdflatex paper_v16editor.tex
bibtex   paper_v16editor
pdflatex paper_v16editor.tex
pdflatex paper_v16editor.tex
pdflatex paper_v16editor_online_appendix.tex
```

Order matters: the `xr` cross-references between main and OA require both `.aux` files to exist before the second main pass; the eight-step sequence settles all references in both documents.

### B. Master files

| File | Role |
|---|---|
| `paper_v16editor.tex` | Main paper master; inputs 15 `sec_*_v16.tex` fragments |
| `paper_v16editor_online_appendix.tex` | OA master; inputs `sec_appendix_v16.tex` |
| `paper_v16editor_highlights.tex` | Author-checklist highlights bullet doc (compiled separately) |

### C. Section fragments

15 input fragments named `sec_*_v16.tex`:

```
sec_frontmatter_v16.tex     sec_introduction_v16.tex
sec_literature_v16.tex      sec_institutional_v16.tex
sec4_data_v16.tex           sec5_emp_v16.tex
```

Each fragment is byte-modifiable independently. The `_v16` suffix decouples them from the `_v15` fragments preserved in `work/v15-editor/`, so editing v16 fragments cannot regress v15.

The same symlink targets are reused by `work/v15-editor/`, so v16 and v15 share a single source of truth for every numerical/tabular dependency. Modifying any shared resource propagates to both versions; this is intentional for `values.tex` and `references.bib` (the upstream pipeline is the authoritative source) and benign for the table fragments and figure PDFs that no v15-only convention currently overrides.

v15 build: byte-stable.

## V. How headline numbers are linked

### A. Macro registry

`work/v13/values.tex` is the authoritative source for every numerical claim that appears in the paper, with two exceptions documented below. Each macro definition is preceded by a `% src:` comment recording the source script and CSV row:

```latex
% src: scripts/54_threshold_table_q3iqr.R :: output/threshold_table_q3iqr/...
\newcommand{\valFL}{2{,}735}
% src: scripts/49_imhof_incremental_value.R :: output/imhof_incremental/imhof_incremental.csv
\newcommand{\valImhofFLBin}{0.903}
% src: scripts/40_leakage_audit_d3.R :: output/leakage_audit/leakage_audit.csv :: structural CV range
\newcommand{\valLeakStructLow}{0.86}
\newcommand{\valLeakStructHigh}{0.89}
```

Total macros after Subprompt 7: **$\sim$235**, organized into 17 thematic blocks (sample frame, AUCs and CIs, headline range, threshold sensitivity, Imhof comparison, leakage decomposition, theory bridge, sign-reversal decomposition, etc.).

### B. Subprompt 7 additions

Six new macros were added in this pass to bind previously-hardcoded numbers in §1, §6, and the abstract:

```
\valAUCprePostCIlo {0.713}
\valAUCprePostCIhi {0.783}

\valLeakStructLow  {0.86}
\valLeakStructHigh {0.89}
\valLeakTautLow    {0.10}
\valLeakTautHigh   {0.13}
```

Substitutions in the manuscript:
- `sec_frontmatter_v16.tex`: `0.903 vs.\ 0.888` → `\valImhofFLBin vs.\ \valImhofFull`; `Cohen's $d$ up to $+1.00$` → `\valBridgeUniqWinD`

- `sec_cade_v16.tex`: `[0.713, 0.783]` → `\valAUCprePostCI`; `0.86$--$0.89` → `\valLeakStructLow$--$\valLeakStructHigh`; `0.10$--$0.13` → `\valLeakTautLow$--$\valLeakTautHigh`
- `sec_conclusion_v16.tex`: `Cohen's $d$ up to $+1.00$` → `\valBridgeUniqWinD`

After this pass, every consequential numerical claim in v16 abstract, §1, §6, §7.2, §10, and §12 is macro-bound. The two remaining exceptions are documented in §VII below.

## VI. Standardized paths/macros for v16

### A. Path conventions (used uniformly)

| Path inside `\input{}`/`\includegraphics{}` | Resolves via | Authoritative location |
|---|---|---|
| `./output/tables/tab_*.tex` | `output → ../v13/output` | `work/v13/output/tables/` |
| `./output/figures/fig_*.pdf` | same | `work/v13/output/figures/` |
| `./tables/tab_*.tex` | `tables → ../v15-editor/tables` | `work/v15-editor/tables/` |
| `./images/fig_*.pdf` | `images → ../v15-editor/images` | `work/v15-editor/images/` |
| `values.tex` (in preamble) | `values.tex → ../v13/values.tex` | `work/v13/values.tex` |
| `references.bib` (in `\bibliography{}`) | `references.bib → ../v13/references.bib` | `work/v13/references.bib` |

### B. Macro convention

All numerical macros are namespaced `\val<Topic><Specific>` (e.g., `\valAUCFLfirm`, `\valBetaUnwOverlap`, `\valBridgeDirectD`). Confidence intervals follow the pattern `\val<Macro>CIlo`, `\val<Macro>CIhi`, `\val<Macro>CI`. The wrapping `\val<Macro>CI` macro is constructed from the `lo`/`hi` pair to avoid duplication.

### C. Cross-document references

`xr` package is loaded in both masters; the main paper references the OA via `\externaldocument{paper_v16editor_online_appendix}` and vice versa. Cross-doc refs use prefixes (`\ref{prop:screening_value}` resolves to OA's Proposition 1).

## VII. What remains manual

Five items are currently manual and intentionally kept so. Each is documented with the rationale and the trigger that would convert it to automated.

1. **`tab_conditional_descstats.tex`** — One-time descriptive statistics table; values stable since v4. Re-generation would require a small R script consuming `BEC_collapse_final.parquet`. **Trigger:** if descriptive stats need updating (e.g., new sample), implement a `61_descstats_table.R` script. Currently low priority.
2. **`tab_mccrary.tex`** — RDD density-discontinuity diagnostic; values are quoted from the failed RDD design and have not changed since computation. **Trigger:** if the McCrary test is re-run with different bandwidth.
3. **`fig_01_losses_distribution`, `fig_02_iqr_identification`, `fig_14_oversight_heterogeneity`** — Three appendix figures that have been visually stable since v4. The PDFs live in `work/v15-editor/images/`. **Trigger:** if any figure needs visual revision, re-generate via `scripts/04_figures.R`.
4. **`scripts/99_make_paper_values.R` does not yet ingest Subprompt-3/4/7 outputs.** The macros for `\valBetaUnwOverlap`, `\valBridgeUniqWinD`, `\valLeakStructLow`, etc. are appended manually to `values.tex`. **Trigger:** before the first R&R submission, wire these into `99_make_paper_values.R` so a single `Rscript scripts/00_master.R` rebuilds the entire macro registry. This is Subprompt-7-residual work, not Subprompt-7 work.
5. **The `tab_cade_fl_firms.tex` table in §6.5** is hand-coded inline in `sec_cade_v16.tex` (3 firms with cartel + CADE process metadata). The table is small and qualitative; values are stable. **Trigger:** if the firm list expands, generate from `cade_bec_crossmatch.csv` via a new `62_cade_fl_firms.R` script.

These five items are catalogued in this memo so that future maintainers know exactly which manual interventions exist and what would automate them.
