## Thesis
The minimum-bidder rule (>=3 participants in convite) creates mechanical
demand for cover bidders, facilitating the very collusion it was designed
to prevent. 39.2% of FL-present convites have n_genuine < 3.

## Key Content
1. Corner vs interior solution: rule forces m = 3 - n cover bidders
2. Pregao vs convite asymmetry: 9.3% vs 3.8% price gap
3. Oversight gradient: 12.5x between PBU Q1 and Q4
4. 23.5% of FL-present convites = pure cover bidding (n_genuine = 0)
5. Welfare: R$74-211M losses from the rule
6. Welfare-optimal screening threshold: W(t) function
7. Audit roadmap: Screen -> Triage -> Investigate
